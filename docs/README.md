## Excluded historical archive

`docs/specs/`, `docs/adr/`, `docs/compiler-benchmark.md`, and `docs/assets/` preserve historical design, decisions, measurements, and illustrations. They are excluded from the current product contract and package publication. Numbered formats, checkpoint preservation, autonomous triggers, recall, signatures, replay, and benchmark commands described there are retired. Historical receipts do not establish acceptance for the current implementation. Existing `.work`, receipts, stored data, and session files are preserved.

The framework-removal decision in ADR 0002 remains applicable; its former support-module inventory and compatibility gates describe the old implementation only. No new ADR is introduced by this reduction.
